# Plugin API for inf-20100630-1340

A Bukkit-style API. Plugins are jars with a `plugin.yml` at the root and a main class that extends `JavaPlugin`.

## Setup

Add `TheWellosInfdevServer-API-inf-20100630-1340.jar` as a compile-time dependency (scope `provided`). Do not put it in the server; the server already contains it.

```sh
javac -cp TheWellosInfdevServer-API-inf-20100630-1340.jar -d out $(find src -name '*.java')
cp src/plugin.yml out/
jar cf MyPlugin.jar -C out .
```

Copy `MyPlugin.jar` into the server's `plugins/` folder and restart.

## plugin.yml

```yaml
name: HelloPlugin
version: 1.0
api: inf-20100630-1340   # the build the plugin is made for (this is the default when the line is missing)
main: com.example.hello.HelloPlugin
author: Your name
description: Example plugin
depend: []        # required plugins
softdepend: []    # optional plugins loaded first
commands:
  hello:
    description: Greets the player
    usage: /<command> [name]
    aliases: [greet]
    permission: hello.use   # ".use" and ".default" are open to everyone; others need operator status
```

## Example

```java
public class HelloPlugin extends JavaPlugin implements Listener {

    @Override
    public void onEnable() {
        getConfig().addDefault("welcome-message", "&aWelcome, %player%!");
        saveConfig();                                   // plugins/HelloPlugin/config.yml
        getServer().getPluginManager().registerEvents(this, this);
        getServer().getScheduler().runTaskTimer(this, new Runnable() {
            public void run() { getServer().broadcastMessage("&6Announcement!"); }
        }, 20L * 60, 20L * 60 * 5);                     // after 1 minute, then every 5 minutes
    }

    @Override
    public boolean onCommand(CommandSender sender, Command cmd, String label, String[] args) {
        if (cmd.getName().equals("hello")) {
            sender.sendMessage(ChatColor.YELLOW + "Hello!");
            return true;
        }
        return false;                                   // false shows the usage message
    }

    @EventHandler
    public void onJoin(PlayerJoinEvent e) {
        e.getPlayer().sendMessage(getConfig().getString("welcome-message").replace("%player%", e.getPlayer().getName()));
    }

    @EventHandler(priority = EventPriority.HIGH, ignoreCancelled = true)
    public void onBreak(BlockBreakEvent e) {
        if (e.getBlock().getType() == Material.BEDROCK) e.setCancelled(true);
    }
}
```

A complete example is in `plugins/example/`.

## Packages

| Package | Contents |
|---|---|
| `net.thewellodev.api` | `TheWello` (static access), `Server`, `World`, `Location`, `Material`, `ItemStack` |
| `...api.entity` | `Player`: messages, teleport, kick, location, health, inventory, game mode |
| `...api.block` | `Block`: type, data, neighbours |
| `...api.command` | `Command`, `CommandSender`, `ConsoleCommandSender`, `PluginCommand`, `CommandExecutor` |
| `...api.event` | `Listener`, `@EventHandler`, `EventPriority`, `Cancellable` |
| `...api.event.player` | Join, quit, kick, login, chat, command, move, drop, pickup, attack, damage by player, death, respawn, health, inventory |
| `...api.event.block` | Block break and place (including door changes) |
| `...api.event.world` | Item spawn |
| `...api.event.server` | Server command, plugin enable and disable |
| `...api.plugin` | `Plugin`, `PluginManager`, `PluginDescriptionFile`, `java.JavaPlugin` |
| `...api.scheduler` | `Scheduler`: run, run later, repeat, async |
| `...api.config` | `Configuration`: simple YAML (`getString`, `getInt`, `getBoolean`, `getStringList`, `set`, `save`) |
| `...api.util` | `ChatColor`: `&` colour codes |

## Added in 2.2.0

Nothing was removed or changed: plugins made for an earlier version keep working. New methods:

- `Player`: `getEyeLocation()` (the feet location plus 1.62), `getTargetBlock(maxDistance)` (the first block on the line of
  sight that is not air or liquid, or `null`), `getLoginTime()` (milliseconds since 1970).
- `World`: `getNearbyPlayers(center, radius)` (nearest first), `fill(x1, y1, z1, x2, y2, z2, typeId, data)` (at most 32768
  blocks, returns the number of blocks that changed, throws `IllegalArgumentException` for a box that is too large or a
  block that does not exist), `getDayLength()`, `isDay()`, `isNight()`, `getBlockLightAt(x, y, z)` and `getSkyLightAt(x, y, z)` (the stored light, 0 to 15; -1 when the
  build has no light or the chunk is not in memory).
- `Server`: `getOperators()`, `getBannedPlayers()`, `getWhitelistedPlayers()`, `broadcastMessage(message, permission)`
  (only players with the permission, and the console), `matchPlayers(partialName)`, `getUptimeMillis()`.

## Added in 2.3.0

Nothing was removed or changed: plugins made for an earlier version keep working. The new methods follow the names of the Bukkit
API of the time and only exist where this build has what they need. Most of them are `default` methods of the interfaces.

- `net.thewellodev.api.util.BlockFace` (shared): `NORTH` (towards a lower x), `EAST` (lower z), `SOUTH` (higher x), `WEST`
  (higher z), `UP`, `DOWN`, the four corners and `SELF`, with `getModX()`, `getModY()`, `getModZ()` and `getOppositeFace()`.
  `net.thewellodev.api.util.Vector` (shared): `add`, `subtract`, `multiply`, `length`, `distance`, `dot`, `crossProduct`,
  `normalize` and `clone`.
- `Location`: `add(location)`, `subtract(location)`, `subtract(dx, dy, dz)`, `multiply(factor)`, `zero()`, `length()`,
  `lengthSquared()`, `toVector()`, `getDirection()` (a vector of length 1 from the yaw and the pitch), `locToBlock(double)`,
  `equals` and `hashCode` (the world, the position and the look direction).
- `Block`: `isEmpty()`, `isLiquid()`, `getRelative(face)`, `getRelative(face, distance)`, `getFace(block)` (the side on
  which another block touches this one, or `null`), `getChunkX()`, `getChunkZ()`.
- `World`: `getBlockTypeIdAt(location)`, `getHighestBlockYAt(location)`, `getHighestBlockAt(x, z)`,
  `getHighestBlockAt(location)`, `getMaxHeight()` (128), `getChunkCoord(blockCoord)`.
- `Server`: `getViewDistance()` (`view-distance`), `getSpawnRadius()` (`spawn-protection`), `getWorlds()` (the one world,
  in a list), `getWorld(name)`, and the Bukkit names `getOnlineMode()`, `hasWhitelist()`, `matchPlayer(name)` and
  `broadcast(message, permission)`.
- `Player`: `performCommand(commandLine)` (as if the player typed it), `teleport(otherPlayer)`.
- Events: `BlockPlaceEvent.getBlockPlaced()` and `getReplacedTypeId()` (the type of the block that is replaced: the event
  comes before the change), `PlayerRespawnEvent.isBedSpawn()` (always `false`: the build has no beds).

What the Bukkit API has and this build has not is not in the API: no entities other than players
(and the items, mobs and entities the build has), no several worlds, no chunk objects, no redstone, no recipes, no custom
world generators.

## Rules

- Touch the world and players only from the main server thread: events, commands and scheduler tasks run there. `runTaskAsync` tasks must not touch the world.
- Colours use `&0`-`&f`.
- Block Y ranges from 0 to 127.
- Cancelling an event stops the server's default action (for example a cancelled block break leaves the block in place).

## Anti-cheat events

`PlayerHealthEvent` and `PlayerAttackEvent` are fired for checks the server itself does not enforce. Without an anti-cheat plugin, nothing is checked. `TheWelloNoCheat` is a reference implementation.

## Versioning

The protocol version is in `Protocol.VERSION`. Plugins compiled against this API work with any server of the same API version; new methods are added without removing old ones.
