# inf-20100607 (Infdev 20100607)

Support added after inf-20100420. Protocol number 23. SHA-256 of the original jar:
`c31c923de4dbc1dcf334e1947eb566ff0046908a69cee4772631662f228bec8f`.

## What the build changes (jar compared with 20100420, and the wiki page)

The wiki page lists doors, ladders and signs, new water and lava textures, saplings that grow into small trees, rarer hostile
mobs, a model for the giant, and no big trees in the generated land; it also lists bugs of the game with doors, ladders and
signs (they belong to the original game). The jar has the same packages and about 320 classes; names moved, which was worked
out by comparing the shape of the classes and then the bytecode of their members:

- **Blocks:** the block base class is `a/a/b/y` (was `x`), sand `a/a/b/x` with its fall method `h` (was `w`, `e`), the furnace
  `a/a/b/t`; new blocks are the sign (63), the door (64) and the ladder (65). There are no wall signs.
- **Chunk** (`a/a/e/d`): the fields from the meta data on moved by one letter (meta `i`, sky light `j`, block light `k`, height map
  `l`, lowest height `m`, tile entities `n`).
- **Entities and items:** fields of the entity classes moved by a letter (the positions did not), the item stack is `a/b/m`.
- **Client:** the biped model is `client/b/i`, the HUD `client/c/m`, the entity render manager is set up with the font too (for the
  text of signs), and there is a renderer for tile entities (`client/a/d`) and a window for writing a sign (`client/c/a/k`).
- **Seeding:** only the world and the noise classes make a `Random` of their own.

## What the server and the client do about it

- **Bridge** (`TWBridge607`), **client mod** (`TW607Client`) and **plugin API** (`net.thewellodev.api607`) are those of 20100420 with
  the names above.
- **Signs:** the server keeps the four lines of every sign (tile entity `Sign` with `Text1` to `Text4` in the chunk files, as the
  game writes them). When a player closes the sign window, the client sends the lines (tile data type 3, at most 15 characters
  a line); the server passes them to the other players and sends them with the chunk.
- **Client patcher:** recognised by the tile entity renderer package and the new block classes; the hooks of 415 with the names above
  (`ClientPatcher.createTransformer607`).
- **World takeover:** the same Alpha level format. From 20100420 the chunk files are moved over as the files they are, in the
  background; from older builds as into 420. The older world is deleted when every chunk is over (`delete-old-world`).
- Plugin API: `net.thewellodev.api607`, and the four bundled plugins.
