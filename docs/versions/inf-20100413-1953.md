# inf-20100413-1953 (Infdev 20100413-1953)

Support added after inf-20100330-1611 (the build 20100413-1951 between them has no known copy). Protocol number 19. SHA-256 of the
original jar: `6b9513e811a83cbf81ac57bc0c8d01a02fa3f0a88a284afe08a5145961002679`.

## What the build changes (jar compared with 20100330-1611, and the wiki pages of 1951 and 1953)

The wiki page of 1953 says its changes are not known; the changes of the lost build 1951 are in this jar. The jar has 4 more
classes than 20100330-1611 and 125 of the 234 old classes are identical; the rest moved or changed.

- Wiki, 1951 (lost): the terrain has sand and gravel beaches and erosion; big ("fancy") trees were added and the small trees of
  the generator now have the shape of the smallest big tree; leaves no longer decay; arrows no longer make mobs when they hit a
  block; the debug screen (F3) got "All" and "Counted"; the tag `id:LocalPlayer` is gone from the saved player. Fixed in 1951: a
  block cannot be placed in the player's own space, a block was sometimes placed twice, some new chunks were too dark until a
  block update, a dead player left a body, the respawn button made several players, saplings grow into small trees again.
  Bugs listed: placing torches, saplings or flowers can crash the game ("more information needed"); sand or gravel above the lava
  void makes lava rise; random lag when chunks update.
- **New names.** The world class is `net/minecraft/a/a/g` again (it was `f`; `a/a/f` is now the box of a light update, and the
  sky-light enum is `a/a/e`). The entity classes changed: the living entity is `a/c/f`; `a/c/e` is the **entity registry** now
  (two static maps and a method that makes an entity from its saved tags and a world); the base entity `a/c/b` got a field `c`
  in front of the others, so **every field of the entity classes has a name one letter further** (position g, h, i became h, i,
  j; motion j, k, l became k, l, m; the box q became r; the ground flag r became s; the dead flag t became u; the previous
  position A, B, C became B, C, D; the no-clip flag E became F; fire I became J; in the living entity T, U, af, ag, ah became U, V,
  ag, ah, ai and health W became X; the player's name R became S; the item entity's pick-up delay N became O; the arrow's fields Q
  and R became R and S).
- **World members:** player `d`, time `c` (a long), provider `w`, listeners `v`, the list of entities `a`, the list of tile
  entities `b`, the light queue `m` and the scheduled ticks `n`; the tick is `i()`, the entity tick is `c()`, the tile get is
  `i(III)`. The light queue is worked off by `h()`, which handles up to 100000 steps in one call and returns whether more is left
  (it was `g()`, one step a call; `g()` returns the queue's size now).
- **Chunks hold entities** (a list for each 16 blocks of height, and methods to add and remove an entity). The chunk fields are the
  ones of 20100330-1611 (blocks `f`, populated flag `d`, tile entities `m`).
- **The mobs cannot be made:** the classes of the sheep, pigs, zombies, skeletons, creepers and spiders (`a/c/a/*`, `a/c/b/*`) have
  no constructor in this jar, and nothing makes them any more (the spawner of the controller fails with a stack trace in every
  tick; see the patcher). The primed TNT and the arrow still exist.
- **The client:** the public `a(world)` of the main class sets the world to null now (it is what leaving a world calls); the method
  that sets a world is the private `a(world, message)`. The renderer, the screens, the digging controller and the settings class
  keep the names of 20100327.

## What the server and the client do about it

- **Bridge** (`TWBridge413`): `TWBridge330` with the names above. The light queue is worked off with `h()` (called until the queue is
  empty), and the stand-in player of the block ticks has its position in `h`, `i` and `j`. The shared tick helper (`TWTick`) reads
  the entity fields with a shift of one letter for this build. The class loader seeds the random numbers of the world, the noise
  and the big tree (they make a `Random` of their own), cuts out the save method of the world, and cuts the sweep of random block
  ticks out of `i()`.
- **Client** (`TW413Client`): `TW330Client` with the names above. The mob classes that have no constructor are skipped (only the
  primed TNT and the arrow are shared), and the world is set with the private method. The patcher uses the hooks of 327 with the
  names of this build (`ClientPatcher.createTransformer413`) and makes the game's mob spawner do nothing.
- **World takeover:** the world of this build is in the same Alpha level format as 20100327. From 330-1611 the chunk files are
  moved over as the files they are, in the background (`/convertworld`, a few chunks in each tick, and each chunk when it is
  needed); from older builds as into 327. The older world is deleted when every chunk is over (`delete-old-world`). The beaches,
  the erosion and the big trees only appear in land that is made after the takeover; the converted chunks stay as they were.
- Plugin API: `net.thewellodev.api413`, and the four bundled plugins. Shared items, game modes, explosions, chests and furnaces: as in 330-1611.
