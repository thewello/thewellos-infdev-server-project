# inf-20100420 (Infdev 20100420)

Support added after inf-20100415. Protocol number 22. SHA-256 of the original jar:
`6ac2fd02255322c01341930d50f71015fa501b234f2c8d7ce8c52206d9c2fb17`.

## What the build changes (jar compared with 20100415, and the wiki page)

The wiki page says: saplings grow into big trees; mobs spawn less often and move differently; the level generator is much faster
and makes less mountainous land with more hills and plains; the game saves more often and "the world save format was changed"
(without details); the debug screen lost the "Counted" value; two bugs are fixed (hostile mobs in bright places, lag spikes from
chunk updates). The jar has the classes of 20100415 except one that is gone; 22 classes differ, and no class or member was renamed:

- **Generator** (`a/a/c/a`, `a/a/c/a/a`, `a/a/c/a/c`): the noise is worked out in arrays, which is what makes it faster.
- **Chunk provider** (`a/a/e/a`): a new method `a()` that returns a boolean; the game's tick (`a/a/g.i()`) and a new method
  `k()` of the world call it to work off the chunks that wait to be saved. The chunk method `d()` is gone and the light enum got a
  number.
- **Chunk files:** the strings of the chunk classes are the same as in 20100415; no difference in the tags was found.
- Mob classes and the renderer changed inside; their names are those of 20100415.

## What the server and the client do about it

- **Bridge** (`TWBridge420`), **client mod** (`TW420Client`) and **plugin API** (`net.thewellodev.api420`) are the ones of
  20100415. The stand-in chunk provider of both answers the new boolean method with `false` (there is nothing to save here). The
  class loader seeds the random numbers and cuts out the save method, the random block tick sweep and the sand fall with the same
  classes as in 415.
- **Client patcher:** 20100415 and 20100420 have the same class names, so the patcher tells them apart by the checksum of the world
  class. It uses the hooks of 415 (`ClientPatcher.createTransformer420`).
- **World takeover:** the same Alpha level format. From 20100415 the chunk files are moved over as the files they are, in the
  background (`/convertworld`, a few chunks in each tick, and each chunk when it is needed); from older builds as into 415. The older
  world is deleted when every chunk is over (`delete-old-world`). The new, flatter land only appears in chunks made after the takeover.
- Plugin API: `net.thewellodev.api420`, and the four bundled plugins. Everything else as in 20100415.
