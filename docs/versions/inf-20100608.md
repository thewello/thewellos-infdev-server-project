# inf-20100608 (Infdev 20100608)

Support added after inf-20100607. Protocol number 24. SHA-256 of the original jar:
`4618eef4c238825df47489600ff2c2c0b1c772626ea6190c7c6fb49ea39aaf3b`.

## What the build changes (jar compared with 20100607, and the wiki page)

The wiki page calls it a bug fix build: entities have shadows again, doors turn better, signs are mined much faster and drop
themselves, doors can no longer be duplicated or placed on farmland, sign particles and two signs side by side were fixed, and
the water and lava textures are aligned. The jars have the same 320 classes and 23 differ; no class or member was renamed. Two
signatures changed: the sign block (`a/a/b/aj`) takes one more number in its constructor (what it drops), and the arrow got a
constructor that takes only the world.

## What the server and the client do about it

- **Bridge** (`TWBridge608`), **client mod** (`TW608Client`) and **plugin API** (`net.thewellodev.api608`) are those of
  20100607. Signs, the shared text of signs, doors, ladders, sand, items and mobs work as there.
- **Client patcher:** 20100607 and 20100608 have the same class names, so the patcher tells them apart by the checksum of the
  sign block class. It uses the hooks of 607 (`ClientPatcher.createTransformer608`).
- **World takeover:** the same Alpha level format. From 20100607 the chunk files are moved over as the files they are, in the
  background; from older builds as into 607. The older world is deleted when every chunk is over (`delete-old-world`).
- Plugin API: `net.thewellodev.api608`, and the four bundled plugins.
