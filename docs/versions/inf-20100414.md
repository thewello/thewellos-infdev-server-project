# inf-20100414 (Infdev 20100414)

Support added after inf-20100413-1953. Protocol number 20. SHA-256 of the original jar:
`9eb3b22601b3871a4dd8cec36f4af9310ae052fd04442da0590353caa441079b`.

## What the build changes (jar compared with 20100413-1953, and the wiki page)

The wiki page lists two fixes and no additions: placing torches, saplings and flowers no longer crashes the game, and random
lag spikes when chunks update were fixed (the page says some remain). The two jars have the same 307 classes; one class differs,
`net/minecraft/a/b/d`, the code that uses an item on a block. It now checks the block that the item places before it uses the
item up, which is the crash fix. Nothing else changed: class names, field names, the world format (Alpha level format) and the
network messages of the game are those of 20100413-1953. The lag fix is not in the classes that were compared, so the jar
holds nothing the server or the client has to treat differently.

## What the server and the client do about it

- **Bridge** (`TWBridge414`), **client mod** (`TW414Client`) and **plugin API** (`net.thewellodev.api414`) are the ones of
  20100413-1953 with the name of this build. The class loader seeds the random numbers and cuts out the save method and the
  random block tick sweep with the same classes; the sand and gravel of the build fall by cells as in 413.
- **Client patcher:** the jars of 20100413-1953 and 20100414 have the same class names, so the patcher tells them apart by the
  checksum of the item-use class. It uses the hooks of 413 (`ClientPatcher.createTransformer414`) and makes the game's mob
  spawner do nothing (the mob classes of these builds have no constructor).
- **World takeover:** the same Alpha level format. From 20100413-1953 the chunk files are moved over as the files they are, in the
  background (`/convertworld`, a few chunks in each tick, and each chunk when it is needed); from older builds as into 413. The older
  world is deleted when every chunk is over (`delete-old-world`).
- Plugin API: `net.thewellodev.api414`, and the four bundled plugins. Shared items, game modes, explosions, chests and furnaces:
  as in 20100413-1953.
